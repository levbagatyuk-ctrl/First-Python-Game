# Ліс відлунь / Echo Forest

Завершена невелика 2D action RPG українською мовою. Основна гра написана на **Python + pygame-ce**. Той самий код працює на комп'ютері та у браузері через **pygbag / WebAssembly**.

Мандрівник із вашого зображення досліджує ліс, знайомиться з Мірою, перемагає охоронців трьох джерел світла й Вартового тіні та повертає життя лісу. Є фінал історії й можливість продовжити дослідження.

## Найпростіша публікація на Netlify

Готова збірка вже знаходиться в папці **`dist/`**. Архів **`netlify-deploy.zip`** містить ті самі файли.

1. Відкрийте [Netlify Drop](https://app.netlify.com/drop) і ввійдіть у свій обліковий запис.
2. Перетягніть **папку `dist`** у зону завантаження. Якщо користуєтеся архівом, спочатку розпакуйте його й завантажте папку, де лежить `index.html`.
3. Netlify видасть посилання `https://назва.netlify.app` — ним можна ділитися.

Для такого завантаження Python на Netlify не потрібен: `dist` — готові статичні файли. Гра завантажує версію 0.9.3 середовища Python/WebAssembly з офіційного CDN `pygame-web.github.io`. Тому потрібен інтернет; перший запуск може тривати до хвилини. Коли з'явиться меню або повідомлення «Ліс готовий», натисніть усередині гри. Повністю автономний офлайн-запуск вебверсії не налаштований.

**Не завантажуйте весь проєкт вручну замість `dist`.** Netlify Drop має отримати готовий `index.html` на верхньому рівні. Не відкривайте цей HTML подвійним кліком: WebAssembly потрібен HTTP-сервер.

## Запуск на комп'ютері

Потрібен Python 3.10 або новіший.

**macOS:** можна двічі натиснути `Грати.command`. Перший запуск встановить залежність у локальне віртуальне середовище.

**Windows:** двічі натисніть `Грати.bat`. Потрібен встановлений Python із доступною командою `py`.

Або через термінал:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python RPG_Game.py
```

У Windows замість перших двох команд:

```powershell
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
```

В IDE виберіть інтерпретатор `.venv/bin/python` (macOS/Linux) або `.venv\Scripts\python.exe` (Windows) і запускайте `RPG_Game.py`.

## Як грати

| Клавіші | Дія |
| --- | --- |
| WASD або стрілки | Пересування |
| Space або ліва кнопка миші | Удар мечем; Space можна утримувати |
| Q | Магічний постріл у найближчого ворога; витрачає 22 мани |
| Shift | Ривок у напрямку руху з короткою невразливістю |
| E | Поговорити, відкрити скриню, пробудити джерело, відпочити |
| F | Зілля: відновлює 65 HP |
| Tab | Мапа |
| I | Рюкзак, характеристики та журнал завдань |
| Esc | Пауза / закрити вікно |
| H | Допомога |
| V | Увімкнути / вимкнути звук |

Літерні клавіші працюють і з українською розкладкою.

На сенсорному екрані після першого дотику з'являються джойстик і кнопки. Для телефона зручніші горизонтальна орієнтація та повний екран. Повноекранний режим залежить від можливостей браузера; якщо API недоступний, кнопка відкриває гру окремо.

### Маршрут пригоди

1. Знайдіть Міру трохи вище вогнища й поговоріть із нею (`E`).
2. Йдіть стежками до трьох джерел; їх видно на мапі (`Tab`).
3. Здолайте трьох охоронців кожного джерела й активуйте його (`E`). Джерело відновлює HP і ману, дає досвід та золото.
4. Купуйте зілля, поліпшуйте меч і броню в Орина біля прихистку.
5. Коли три джерела сяють, здолайте Вартового біля брами на північному сході та активуйте браму (`E`).

Мана відновлюється сама. Удари ворогів позначаються червоним колом — встигніть відійти або зробити ривок. Вогнище безкоштовно відновлює HP, ману й запас щонайменше двох зіль. Після поразки герой повертається до прихистку та втрачає 15% золота; завдання, здобутки й спорядження залишаються.

## Збереження

- Автозбереження кожні 12 секунд, після важливих подій та під час паузи. У меню паузи також є окрема кнопка збереження.
- На комп'ютері файл: `~/.echo_forest/save.json`. Для іншого місця можна задати змінну `ECHO_FOREST_SAVE`.
- У браузері: `localStorage` цього сайту, ключ `echo-forest-save-v1`. Продовження доступне в тому самому браузері на тому самому домені. Збереження не синхронізуються між пристроями.
- Приватний режим, очищення даних сайту або зміна домену можуть прибрати доступ до збереження. Якщо сховище заблоковане, гра покаже повідомлення та залишиться придатною для гри в поточній вкладці.
- Нова гра просить підтвердити заміну попереднього збереження. Пошкоджений файл не спричиняє аварійне завершення.

## Перезібрати після зміни коду

В активованому віртуальному середовищі:

```bash
python -m pip install -r requirements-build.txt
python scripts/build_web.py
```

Скрипт оновлює `dist/` і `netlify-deploy.zip`. Він пакує лише файли гри та її ресурси; середовище `.venv`, тести й збереження до публікації не потрапляють.

Для локальної перевірки:

```bash
python scripts/preview.py
```

Відкрийте **http://127.0.0.1:8000**. Зупинка сервера: `Ctrl+C`.

### Автоматична публікація з Git

Додайте вихідні файли до власного Git-репозиторію та під'єднайте його до Netlify. У корені є `netlify.toml`:

- **Build command:** `python -m pip install -r requirements-build.txt && python scripts/build_web.py`
- **Publish directory:** `dist`
- **Python:** 3.12

Налаштування сторінок, секрети й серверна база даних не потрібні. Після змін у Git Netlify збирає гру повторно. Папка `dist` і локальна `.venv` навмисно виключені з Git.

## Перевірки

```bash
python -m unittest discover -s tests -v
```

Тести перевіряють прохідність усіх цілей за реальною геометрією колізій, бойові дії, захист під час ривка, покупки, одноразовість скринь, відродження, збереження, усі екрани та повну послідовність завдань до фіналу. Для тестів використовується віртуальний дисплей pygame; ігрове збереження користувача не змінюється.

Додаткова перевірка в Chrome (не потрібна для гри або публікації):

```bash
python -m pip install playwright
# На macOS скрипт використовує встановлений Google Chrome.
# На інших системах: python -m playwright install chromium
python scripts/preview.py --port 8765
# В іншому терміналі з тим самим venv:
python scripts/browser_smoke.py
```

Скріншоти й журнал перевірки записуються до `artifacts/`. Браузер запускається з окремим тестовим профілем.
